# ORVION Community — Join Page

Static, dependency-free website suitable for Vercel.

## Deploy
1. Upload these files to a new GitHub repository named `orvion-join`.
2. Import the repository in Vercel as an **Other** framework project. No build command or output directory needed.
3. Copy the final public HTTPS domain from the successful deployment.
4. In `index.html`, replace `https://YOUR-LIVE-DOMAIN` (all occurrences) with your actual live base URL, e.g. `https://your-project.vercel.app`. Do **not** use the Discord invite link there. Commit and redeploy.
5. Open the public site and ensure `/og-image.jpg` and `/logo.png` load without signing in.
6. Test the final site URL using https://developers.facebook.com/tools/debug/ , Scrape Again, then share **your site URL**, not `discord.gg`.

## Notes
- The link preview layout is controlled by Messenger. The image, title, and description are provided by this page, but Discord's native live member count/green button are not available in Messenger.
- `logo.png` is a low-resolution **prototype crop** taken from the screenshot supplied in this chat; replace it with the original high-res ORVION logo when available.
- `og-image.jpg` is a branded preview sample, 1200×630. Replace with a refined brand asset anytime; update the filename/version if Messenger caches the old image.
- Discord invite target is `https://discord.gg/ucdUNevNp`; change the anchor href if the invitation changes.
